ระบบบริหารจัดการโครงการแบบบูรณาการ (Enterprise Project Management)

บริหารภาพรวม งบประมาณ ความปลอดภัย และแผนปฏิบัติการ (8T Framework)

1. ข้อมูลระดับโครงการหลัก (Project Master & Core Team)
ทีมงานหลักประจำโครงการ (Core Team)
ข้อมูลสัญญาและงบประมาณรวม
2. กำหนดพื้นที่ปฏิบัติงานและการควบคุมความเสี่ยง (Area / Zone)
3. แผนดำเนินการและแบ่งงาน (Task Execution Plan - อิง 8T Framework)
📥 นำเข้าแผนงานจาก Excel (Import from Excel)
* หรือเพิ่มแผนงานแบบ Manual (ราย Task) ด้านล่าง
4. Dashboard สรุปโครงสร้างโครงการ (Project Breakdown Structure)
รหัส (ID) รายละเอียดโครงการ / พื้นที่ / ภารกิจ ทีมงาน / ผู้รับผิดชอบ (Team) ระยะเวลา (Time) สถานะ
ไม่มีข้อมูล กรุณาสร้างโครงการใหม่
